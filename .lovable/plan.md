# 6100 Partners Corporate Landing Page

## Overview
Build a polished single-page website for 6100 Partners that presents the firm as an institutional-caliber operating partner for sponsors, boards, and founders. Consultation requests will open a pre-addressed email to `brandon.oliver@6100partners.com`, and the scheduling action will use the same direct email contact.

## Page Structure
- Create a restrained top navigation with the 6100 Partners wordmark, section links, and a consultation action.
- Build a full-width hero with a strong enterprise-value proposition, a single primary consultation CTA, and a concise operating-focus statement.
- Add a strategic overview explaining the firm’s partnership model across private equity, healthcare, and complex multi-state operations.
- Present four core practice areas in a crisp, editorial service layout.
- Add a leadership profile for Brandon Oliver, MBA, highlighting 20+ years of operating leadership.
- Create an operating pillars section focused on scalable systems, P&L rigor, and execution speed.
- Build a validated consultation form that composes a detailed email from the visitor’s entries, plus a separate email-based scheduling link.
- Finish with a compact Nashville and national-reach footer.

## Visual Direction
- Deep navy, dark charcoal, warm white, and restrained bronze accents.
- Crisp sans-serif typography with an editorial serif used sparingly for emphasis.
- Sharp geometry, subtle rules, limited shadows, and restrained motion.
- Responsive layouts with accessible contrast, keyboard focus states, and reduced-motion support.

## Technical Details
- Implement the page at `/` using the existing TanStack Start structure and Tailwind v4 design tokens.
- Add route-specific title, description, Open Graph metadata, and Twitter card metadata.
- Keep form behavior entirely client-side using a composed `mailto:` link; no database or external service will be added.
- Add no placeholder or invented phone numbers, street addresses, client logos, or performance claims.
- Verify the finished page in the running preview at desktop and mobile widths.
